# AI Assistant

तीन फाइलें: `index.html`, `style.css`, `script.js`.

## GitHub Pages पर चलाने के स्टेप
1. GitHub पर नया repository बनाएं (Public).
2. इस फोल्डर की सारी फाइलें upload करें (Add file → Upload files).
3. Settings → Pages → Branch: `main` / root → Save.
4. 1–2 मिनट बाद आपका लिंक `https://<username>.github.io/<repo>/` पर चालू हो जाएगा।
5. साइट खोलकर सेटिंग्स में अपनी API key डालें।

API key सिर्फ आपके ब्राउज़र में सेव होती है।
